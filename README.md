# StockMonitor

## 是什么

StockMonitor 是一个基于 Qt5 和 C++17 的轻量级股票监控工具，用于在桌面上快速查看自选股票和主要指数行情。

它支持通过全局快捷键呼出窗口，适合长期后台运行和快速查看行情。

## 主要功能

- 实时刷新自选股票价格、涨跌幅和成交信息
- 支持新浪财经、腾讯财经、东方财富数据源
- 支持 A 股、港股、美股搜索和添加
- 支持上证指数、深证成指、创业板指展示
- 支持股票列表拖拽排序、右键移动和删除
- 支持全局快捷键显示或隐藏窗口
- 支持亮色/暗色主题、窗口透明度、行高和刷新间隔设置
- 支持自动隐藏和系统托盘后台运行

## 支持平台

- Windows 10
- Windows 11

构建环境需要 MSVC、Qt5、CMake 和 OpenSSL。
